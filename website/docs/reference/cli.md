`basalt-core` installs two binaries, and registers three commands with React
Native's CLI.

## `basalt`

```
basalt <command> [directory]

  init     configure an app to build for the desktop
  doctor   report what a build needs, changing nothing
```

## `basalt-bundle`

Bundles an app for release, writing the resolved Expo config beside the bundle.

## Through React Native's CLI

`run-linux`, `run-macos` and `run-windows`, registered by the host packages.
